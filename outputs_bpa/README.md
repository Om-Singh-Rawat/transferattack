# BPA_CNN Adversarial Images Output

This directory contains the generated adversarial images for the newly proposed `BPA_CNN` attack method.

## How these were generated
These images were generated using the `run_vanilla_subset_generation.py` script for each of the 4 Keras attacker models (`Facenet512`, `ArcFace`, `GhostFaceNet`, and `VGG-Face`).
